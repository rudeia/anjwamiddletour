# 순천만 체험활동 미션활동지

스마트폰과 컴퓨터에서 쓰는 정적 웹앱입니다. 서버 계정·빌드·API 키 없이 GitHub Pages에 배포할 수 있습니다.

## 학생 활동

1. 첫 화면의 **나의 답사 시작하기**를 누릅니다.
2. 사전 기록에서 선생님이 배정한 **1~4모둠**을 고르고 학생 정보를 입력합니다.
3. 현장 미션의 **질문 목록 허브**에서 원하는 질문을 골라 작성합니다. 모둠마다 독립된 질문 10개이며, 원자료의 안내처럼 2개 이상 깊이 조사할 수 있습니다. 진행 순서는 강제하지 않습니다.
4. **사진 기록**에서 모둠별 사진 과제 5개에 사진과 설명을 넣습니다. 과제를 열어 촬영할 장면과 직무를 확인합니다.
5. **나의 보고서**에서 체험학습 보고서(A4)와 포스트잇 탐구 보드(A3) 중 결과물 형식을 고릅니다.
6. **체험학습 PDF 다운로드**는 제공된 양식 구조로 글·사진을 정리합니다. **보드 PDF 다운로드**는 꾸민 배치를 그대로 저장합니다.

## 모둠

| 모둠 | 진로·직업 | 구성 |
|---|---|---|
| 1 | 식물원예사(가드너) · 수목의사 | 질문 10개 + 사진 과제 5개 |
| 2 | 전통조경가 · 고건축전문가 | 질문 10개 + 사진 과제 5개 |
| 3 | 조경디자이너 · 공공공간디자이너 | 질문 10개 + 사진 과제 5개 |
| 4 | 전시기획자 · 미디어아트디렉터 | 질문 10개 + 사진 과제 5개 |

제공된 국가정원 직업 탐정단 자료의 직업·직무 질문·증거 사진 과제를 화면에 맞춰 정리했습니다. 참고 사진의 원본 정보는 assets/출처.md에 보관합니다. 각 모둠 직업 소개에서 사진 출처·원본·이용 조건을 확인할 수 있습니다. 1~3모둠은 CC0 사진, 4모둠은 공공누리 제4유형 공식 사진입니다.

## 두 가지 보고서

### 체험학습 보고서 (A4)

제공된 체험학습 PDF의 학생 정보·사전 기대·현장 배움·사진·진로 성찰 구조를 따릅니다. 학생 정보와 사전 기록은 그대로 옮기고, ‘새롭게 알게 된 내용’에는 모둠 답변을 제목과 함께 모읍니다. 진로 항목에는 탐구 직업과 ‘나와 직업’ 답변을 연결합니다. 사진 과제 5장과 설명, 모둠별 질문 10개와 답변 별첨도 포함합니다.

‘보고서 내용 다듬기’에서 학생이 직접 수정할 수 있습니다. 기록하지 않은 감상·실천 계획은 생성하지 않습니다. 이 PDF는 한글 텍스트 검색·선택이 가능합니다.

### 포스트잇 탐구 보드 (A3)

카드 위쪽 손잡이로 위치를 바꿉니다. 카드를 선택하면 색상과 ‘조금 크게·조금 작게’만 보입니다. 숫자 너비/높이·판 설정은 화면에서 제외했습니다. ‘자동 정리’가 내용에 따라 필요한 쪽을 자동으로 만듭니다.

‘스티커로 꾸미기’는 자동 정리 옆 버튼에 있습니다. 도움말은 동그란 느낌표를 눌러 확인합니다. 글이 카드 밖으로 넘치면 자동 정리하거나 카드를 크게 한 뒤 저장합니다. PDF에는 배치와 스티커가 그대로 담기며, 디자인 보존을 위한 이미지 방식입니다.

## 저장과 이어쓰기

상단의 **내용 저장**은 학생 정보·답변·사진·보고서 위치·크기·스티커를 담은 JSON 파일을 저장합니다. **이어서 작성하기**로 다시 열 수 있습니다. PDF는 완성본이며 편집 파일이 아닙니다.

활동은 현재 기기의 localStorage에 자동 저장됩니다. 모둠을 바꾸어도 다른 모둠의 기록을 자동 삭제하지 않습니다. 브라우저 데이터 삭제·비공개 모드·저장 공간 부족에 대비해 JSON을 보관하세요. 저장 한도를 넘으면 안내가 나옵니다. JPG/PNG/WebP 사진을 긴 변 1000px JPEG로 축소하며 HEIC는 JPG로 변환해 주세요.

교사 설정·편집 UI, 계정, 중앙 제출·수합·실시간 동기화는 없습니다. 문항 수정은 소스에서 한 뒤 다시 배포합니다.

## 홈 화면에 추가

상단 **앱 설치**에서 기기별 안내를 확인합니다. 설치를 지원하는 브라우저는 설치 요청으로 연결하고, 아이폰에서는 Safari 공유 → 홈 화면에 추가를 안내합니다. 아이콘과 standalone 실행용 manifest를 포함합니다. 오프라인 재접속 캐싱은 지원하지 않습니다.

## 로컬 실행

이 폴더에서 `python3 -m http.server 4173`을 실행하고 http://localhost:4173 에 접속합니다. 파일을 더블클릭하는 방식 대신 HTTP 서버나 GitHub Pages로 여세요.

## GitHub Pages

프로젝트의 웹 파일과 assets/, vendor/, designs/, .nojekyll을 저장소 루트에 업로드합니다. Settings → Pages → Deploy from a branch → main / (root) → Save로 설정합니다. 스크립트와 스타일은 상대 경로라 하위 저장소 주소에서도 작동합니다.

모든 JS/CSS/manifest/자산을 함께 업로드해야 합니다. 공개 주소: https://rudeia.github.io/anjwamiddletour/

## 디자인 시안

`/designs/`에 Dribbble 사례를 참고해 만든 인터랙티브 시안 3개가 있습니다. 실제 학생 기록과 분리되며 샘플로 동작합니다. A는 질문 지도, B는 포스트잇 탐구실, C는 관찰 여권입니다. B안의 카드 열림·들림·착지·자동 정리 인터랙션만 기존 화면에 적용했습니다. 기존 문구·색상·구조는 유지합니다. 출처 링크는 비교 화면에서 확인할 수 있습니다.

## 공개본 이용 조건

학교 체험학습을 위한 비상업적 교육 앱입니다. 정원도시센터의 공식 후원·인증을 의미하지 않습니다. 사진·글꼴·라이브러리의 조건은 [LICENSES.md](LICENSES.md)와 [사진 출처](assets/출처.md)를 확인하세요. 특히 4모둠 사진은 출처표시·비상업적·변경금지 조건을 준수해야 하며 다른 라이선스와 구분됩니다. 학생 기록은 사이트에 제출되지 않고 사용하는 브라우저와 직접 내려받은 파일에 보관됩니다.

## 사용성 검증

`?qa=1` 주소는 일반 학생 기록과 다른 저장 키를 사용합니다. 시험에는 가상 기록만 입력하며 일반 주소의 저장 기록을 읽거나 덮어쓰지 않습니다. QA 기록과 다운로드 결과는 저장소에 포함하지 않습니다.

# 체험 한 장

정적 교육 웹앱입니다. 계정·서버 업로드 없이 이 기기에 기록을 저장합니다. 사진과 답변은 JSON으로 따로 보관해 주세요. 제목 변경과 무관하게 기존 순천 저장 키를 유지합니다.

## 두 활동

- **예술 교육 페스티벌**: 제공된 체험학습 보고서의 정보·기대 3문항·현장 경험 3문항·사진 최대 3장·의미 3문항을 공통 단계형 입력으로 구성했습니다. 관람/참여 역할 구분 없이 사용하며, 장소와 날짜는 학생이 입력합니다. A4 PDF와 독립 JSON 저장을 지원합니다.
- **순천만 체험학습**: 4모둠별 질문 10개와 사진 과제 5개, 단계형 성찰 보고서, A4 보고서 및 A3 한 장 전시 보드입니다. 현장 미션 완료 기준은 질문 2개 이상과 사진 5장입니다.

## A3 한 장 전시

작성 답변에서 3개 이상, 학생 사진에서 1개 이상을 선택하고 별도의 필수 체험활동 후기를 작성합니다. 체크 해제는 원자료를 삭제하지 않습니다. 최초 진입에만 공백 답변을 제외하고 실제 UTF-8 바이트 수가 큰 답변 3개를 추천하며, 동률은 기록된 작성 순서를 따릅니다. 구형 기록에는 작성 시각이 없어 질문 순서를 안정적인 대체 순서로 사용합니다. 이후 선택은 재진입과 JSON 복원에서 유지합니다.

주제 사진·제목 패널은 답변 영역과 분리됩니다. 포스트잇과 도형 스티커는 자유배치하며 선택/이동/크기/회전/화면 이동 모드를 구분합니다. 너비·높이·각도·글씨체·색상과 위치를 저장합니다. 선택 요소 삭제 버튼은 제어 영역에 표시하며, 상세 크기·각도·글씨 설정은 접어서 열 수 있습니다. 삭제 또는 보드 제외는 되돌릴 수 있으며 원래 답변·사진은 유지합니다. 글 넘침은 경고하고 PDF 저장을 막으며 글씨를 자동 축소하지 않습니다. 전체 보기는 배치 확인용이고 확대 보기는 편집용입니다.

구형 boardLayouts는 보존하고 새 exhibition 상태를 별도로 저장합니다. 구형 공통 post/formalEdits는 당시 선택된 모둠으로만 이전하고 다른 모둠에 복제하지 않습니다. 후기 기본값은 빈 내용입니다. 예술 활동은 별도의 저장 키와 형식을 사용합니다.

## 사진과 설치

JPG·PNG·WebP 한 장 25MB 이하를 읽어 학생 사진만 로컬 저장용으로 압축합니다. HEIC·HEIF는 JPG로 먼저 변환해야 합니다. 실제 기기 카메라와 iOS/Android 설치는 별도 확인이 필요합니다. 앱 설치 버튼은 브라우저 설치 요청이 있을 때만 설치 창을 호출하고, 다른 환경에서는 홈 화면 추가 방법을 안내합니다. 설치가 기록 동기화나 오프라인 보장을 뜻하지 않습니다.

모둠 참고 사진의 출처·조건은 `assets/출처.md`와 `LICENSES.md`를 확인하세요. 1~3모둠은 최광모의 CC0 자료, 4모둠은 정원도시센터 공공누리 제4유형 자료입니다. 4모둠 사진은 비상업적 교육용이며 원본 바이트와 전체 비율을 유지하고 출처·조건을 표시합니다. A3에서는 원본 JPEG를 별도 삽입하여 주제 사진을 캔버스로 재압축하지 않습니다. 공식 후원을 뜻하지 않습니다.

## 로컬 확인

빌드 없이 이 폴더에서 정적 HTTP 서버로 실행합니다. `?qa=1`은 일반 기록과 분리된 검사 저장 키를 사용합니다. 배포 전 모바일 및 실제 PDF 페이지 수·저장복원 회귀 검사를 마쳐야 합니다. 원본 업로드 PDF와 QA 기록은 공개 저장소에 포함하지 않습니다.

## PDF 파일명

`학번_이름_체험명_보고서.pdf` 또는 `학번_이름_체험명_포스트잇보드.pdf`로 저장합니다. 학번은 기존 학년 1자리 + 반 2자리 + 번호 2자리로 구성합니다(1학년 2반 3번 → 10203). 정보가 부족하거나 범위가 맞지 않으면 학번미입력, 이름이 비면 이름미입력으로 표시합니다. 파일명에 사용할 수 없는 문자는 밑줄로 바꾸며 원래 학생 정보는 수정하지 않습니다. 페스티벌에는 보고서 PDF만 있습니다. JSON 백업 파일명과 저장 키는 유지합니다.

모바일 상단의 설치·저장·불러오기는 아이콘으로 표시합니다. 새 기록의 날짜는 기기 현지 오늘 날짜이며 직접 고칠 수 있습니다. 기존 날짜와 답변은 업데이트나 JSON 불러오기 때 오늘 날짜로 바뀌지 않습니다. 페스티벌의 무대 삽화는 이 프로젝트에서 작성한 SVG입니다.

## 순천 활동 순서

사전 정보 → 기대와 질문 → 현장 미션 → 나의 보고서 순서입니다. ‘떠나기 전, 나의 기대와 질문’ 3문항은 학생 정보와 분리된 독립 화면에 있습니다. 이전·다음이나 위쪽 메뉴로 이동해도 입력 내용은 유지됩니다. PDF에는 기존 사전 기록 항목으로 세 답변을 그대로 담습니다.

페스티벌은 마지막 자유 소감을 쓴 뒤 전체 보고서를 확인합니다. 소감은 보고서와 PDF의 마지막 ‘체험활동 소감’ 항목에 들어가며 관람·참여 경험 모두 적을 수 있습니다. 구형 기록에 소감이 없으면 빈 값으로 보존하고 이전 단계에서 추가할 수 있습니다.


### 전시 보드 꾸미기

주제 사진과 제목은 보호된 상단 패널에 표시합니다. 답변 3개·학생 사진 1개를 선택한 새 보드는 사진을 크게 둔 비대칭 콜라주로 시작합니다. 기존 저장 배치는 그대로 유지되며 ‘배치 다시 정리’를 눌러 새 구성을 적용할 수 있습니다. 종이 색·각도·손글씨와 학생 사진은 자유롭게 조절할 수 있습니다.

공용 도구는 스티커 추가·되돌리기·배치 다시 정리입니다. 보드의 요소를 직접 눌러 선택하면 해당 요소의 편집 도구가 나타납니다. 목록 선택은 사용하지 않습니다. 카드 본문과 빈 곳에서는 화면을 스크롤하고, 조작은 선택한 전용 핸들에서 시작합니다. 답변·사진을 보드에서 빼도 원자료는 남고 필수 후기는 보드에 유지됩니다. PDF에는 편집 도구가 포함되지 않습니다.


포스트잇·사진 카드를 직접 누른 뒤 선택한 카드 오른쪽 위의 **⋯** 버튼을 누르면 해당 요소의 이동·크기·회전·보드에서 삭제 메뉴가 열립니다. 메뉴는 보드 가장자리에 잘리지 않게 화면 중앙에 표시되며, 상세 설정에서 종이 크기·각도·글씨도 바꿀 수 있습니다. 스티커는 눌러 선택한 뒤 기존 개별 도구로 조작합니다. 필수 후기의 삭제는 제한됩니다.
